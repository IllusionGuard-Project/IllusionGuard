# IllusionGuard

### 📘 Overview
This repository accompanies the paper  
**“Illicit or Abusive Text is Hidden in Plain Sight: Detecting Concealed Harmful Text in Visual Illusion Images.”**

It releases the **harmful text illusion images** collected from online platforms, together with the **datasets** used in our study.  
In addition, it provides the **dataset generation scripts** and the **source code of IllusionGuard**, aiming to promote reproducibility, transparency, and future research in this area.
